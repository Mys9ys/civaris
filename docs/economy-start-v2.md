## Щелчок день 1 — деньги (канон)

### Эмиссия (привязка к людям)

| Что | Правило |
|-----|---------|
| Эмиссия на человека | **200** (`money_issue_per_person`) |
| Старт | **N × 200** → казна **эмиссией** (без оплаты / без покупки у типографии на щелчке) |
| Тест N=30 | **6000** в казну |
| Новый человек (+5 и т.п.) | казна **+200** в момент появления (ещё не в тике; заложить при росте населения) |

Пособие **100** — это **перевод** из уже эмитированной казны, не новая печать.

### Потоки щелчка

| Что | Сумма | Куда |
|-----|------:|------|
| Эмиссия | **N × 200** | → казна (mint) |
| Пособие человеку | **100** | казна → человек |
| Капитал ЧБ | **1500** (конфиг) | казна → ЧБ |
| Лицензия | **4** | фирма/ЧБ → казна |
| Гроссбух | **4** | фирма/ЧБ → казна |
| Кредит фирмы | **50** @ 15%/год | ЧБ → фирма |
| Абонентка р/с | **2** | фирма → ЧБ, **1-го числа** каждого месяца (в т.ч. в день старта) |

Касса фирмы после щелчка: **50 − 4 − 4 − 2 = 40**.

### Сходится ли при N=30 (17 фирм + ЧБ)

| Карман | После щелчка |
|--------|-------------:|
| Люди (30×100) | **3000** |
| Фирмы (17×40) | **680** |
| ЧБ | **≈676** (капитал 1500 − лицензия/гроссбух 8 − кредиты 850 + абонентки 34) |
| Казна | **≈1644** |
| **Денежная масса** | **6000** |

ЧБ **не** тощает от пособий: пособия платит **казна**, кредиты — **ЧБ**. Кредиты 17×50=**850** < капитала 1500 → хватает.

Летопись = **логи** (короткие строки), без художества.

Код: `WorldService::bootstrapClickEconomy`, таблицы `companies` / `wallets` / `ledger_entries`.

## 2.1. Эмиссия дензнаков (канон комплекта)

Печать не «абстрактный дензнак», а **комплект на сумму 250** с разменом и расходом бумаги.

| Ступень | SKU | Рецепт / состав |
|--------|-----|-----------------|
| Пачка | `pischaya_bumaga_60_listov` | магазин, `contents_qty=60` |
| Порция | `pischaya_bumaga_1_list` | 1/60 пачки (`portion`) |
| Бланк | `denznak_blank` | 0,1 листа (10 бланков с листа 20×25 → купюра 10×5) |
| Номиналы | `denznak_1` / `_5` / `_10` / `_50` | 1 бланк |
| **Комплект** | **`denznak_komplekt_250`** | **1×50 + 3×10 + 18×5 + 80×1 = 250** |

- Купюр в комплекте: **102** ≈ **11 листов** бумаги (теория сырья / размена).
- Ежемесячно при **+5** человек: комплектов ≈ `ceil((5 × наличность_на_человека) / 250)`.
- Зафиксировано в `api/data/catalog_seed.json` (не только в живой БД).

## 4. Принципы причёски (эта итерация)

1. Меньше каскада **%** на себестоимость; фикс — транспорт, абонентка банка, (позже) тарифы услуг.  
2. **Магазин** и **НДС** — проценты (НДС **7%**, маг **10%**, произв. **20%**).  
3. **Инструмент / капитал / проект·наука / здание** (`tool`, `project`, `building`): себест → маржа произв. → НДС, **без** маржи магазина.  
   **Услуга** (`service`): себест → маржа произв., **пока без НДС** (ТРКом тариф — фикс отдельно).  
   Здания: калькулятор сруба в каталоге (`kind=building`, рост куба **60 см**).  
4. Труд: `labor_min` = минуты **на одного**; `labor_workers` — множитель бригады перед % смены / в ФОТ.  
5. Выходной = спрос Харчевни; можно **½ смены** как подработку.  
6. Грейды специальности: пороги **1000 / 2000 / 5000** ч → **+5%** скорости / грейд (+ ЗП).  
7. Казна без штата на старте; одно нац. блюдо / один фрукт на деревню.
