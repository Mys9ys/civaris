# Застройка деревни v1 (редактор карты)

Статус: **канон фазы 0** · тест **1×30**.  
Связь: [`economy-start-v2.md`](economy-start-v2.md) · рост куба **60 см**.

## Жильё

| | |
|--|--:|
| Тип | типовое **общежитие на 10** (`obshchezhitie_10`) |
| Корпусов | **4** (ставим вручную в редакторе) |
| Вместимость | **40** мест |
| На старте | **30** человек → в занятые общаги |

## Общежитие v3 (план «как квартира»)

Снаружи **12 × 5 м**. Внутри:

| | |
|--|--:|
| Комната | **2 × 2 м** (кровать + стол + стул, куб 60 см) |
| Коридор | **1 м** между рядами |
| Холл | **4 × 2 м** (= 2 ячейки) — **не комната**, тот же цвет что коридор |
| Ряд север | **6** комнат |
| Ряд юг | **4** комнаты + холл |

Двери комнат — в коридор (дуга = куда открывается).  
Выход из здания — **из холла во двор** (не на улицу-резерв).  
Цена стройки позже пересчитаем под габарит.

## Ратуша (из каталога `ratusha`)

| | |
|--|--:|
| Сруб | **1000 × 500 × 105** см (как SKU) |
| На карте | **10 × 5 м** |
| Комнаты | **2 × офис 5×5**: склад + зал (1 перегородка) |
| Проект | `proekt_ratushi` (ПрБюро) |
| Выход | из зала **во двор** |

Офисный модуль **5×5** — канон для конторских комнат; в общаге комнаты остаются маленькими (2×2).

## Улица (плитки «как Лего»)

Канон ширины: **16 м** = тротуар 2 + клумба 2 + 2×2 м в каждую сторону + клумба 2 + тротуар 2.  
В редакторе: плитка **`road_tile` 16×16 м** (`kind=road`) и **`road_cross`** (перекрёсток: заходы с 4 сторон, центр без сквозных пунктиров). Плюс на плитке — копия встык (snap).  
Здания на дорогу не ставятся (пересечение блокируется).

## Двор (варианты, выбрать канон)

Выходы домов смотрят **во двор**, не на улицу-резерв. Двор = общее «зелёное» / хозяйственное пространство квартала (деревья, тропинки; позже — колодец, скамейки).

| Вариант | Идея | Плюсы | Минусы |
|---------|------|-------|--------|
| **A. Каре** | 4 общаги по периметру, двор в центре; ратуша на одной стороне двора | Классика деревни, короткие пути | Нужен квадрат ~30–40 м |
| **B. Подкова** | 3 общаги буквой П, 4-я / ратуша замыкает; двор открыт к угодьям | Естественный выход к саду/яблоням | Одна сторона «дырявая» |
| **C. Два двора** | 2+2 общаги, два малых двора; ратуша между ними у «улицы» | Масштаб ближе к 12×5 корпусам | Два узла вместо одного |

Пока в редакторе — ставим вручную, разворачивая корпусами **дверью ко двору**. Шаблоны кварталов — после выбора A/B/C.

## Редактор (монитор деревни)

- Сетка 1 / 5 / 10 м, можно выключить  
- **Нулевой метр** — крест (фиксированные координаты); холст расширяется **плюсиками** по краям (шаг сетки ×1/×5/×10), не от перетаскивания объектов  
- **Статус стройки** (`build_status`: `ready` | `building`): ратуша на старте **строится** (значок каска+молоток); общаги готовы. Кнопка «готово» снимает значок.  

 
- Панель справа: шаблоны + свой силуэт фирмы (название, размер)  
- Клик по шаблону → клик по карте (центр здания) → **сразу БД**  
- Свободная постановка (без принудительного snap)  
- Поворот 90° · **инверсия** (дверь N↔S) · **зеркало** (холл L↔R) · «передвинуть» · **OK закрепить** · открепить · убрать  
- Alt+лкм — сдвиг вида; колесо — зум
