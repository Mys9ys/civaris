# Каталог SKU — упрощённая модель (фаза 0)

Один ряд = одно наименование. **«Бревно» и «Бревно внут» — разные строки.**

## Тип (`kind`)

| kind | Склад | Цены | Пример |
|------|-------|------|--------|
| `raw` | да | `cost` (+ `price_shop`, если продаётся) | Глина 1 кг, вода, яблоко |
| `internal` | да | `cost` | Бревно внут, Глина внут |
| `portion` | да | `cost` (не магазин) | 1 лист из пачки, 1 л из бочки, 1 яйцо из десятка |
| `pack` | да | `price_shop` (+ `cost`) | Кулёк, бочка, ящик |
| `tool` | да | `cost` → маржа → НДС (без маг.) | Топор, лопата, печь, колодец |
| `building` | капитал | `price_internal` = себест→маржа→НДС; BOM из Ш×Д×В | ратуша и др. срубы |
| `project` | нет | `price_internal` = себест→маржа→НДС (без маг.) | проект здания, научная работа |
| `good` | да | `price_shop` (+ `cost`) | конечный продукт: горшок, лепёшка |
| `service` | нет | `price_internal` = себест→маржа (**без НДС** пока); ТРКом — фикс отдельно | перевозка, р/с |

Монетка (магазин): у `good`, `pack` и у `raw` с `price_shop`.  
`is_tool` синхронизируется с `kind=tool` (для старого кода).

Себест в UI: ингр. + ФОТ/произв90 + `cost_amort` + `cost_transport` + `cost_tara`.

### Здание (`building`)

Калькулятор: `web/src/lib/buildingCalc.js` · рост куба **60 см** · бревно 100×15×15.  
Габариты `width_cm` × `length_cm` × `height_cm` + `build_partitions` / `build_windows` / `build_doors` → рецепт (бревно, камень пола, доска, глина, шторы) + труд.  
Цена как у `tool`/`project`: маржа произв. + НДС, без магазина.

Вкладка **Постройки** (`/catalog` → Постройки): создание пары SKU  
`project` (ПрБюро, `proekt_*`) + `building` (СтройКом) со связью `pair_sku_key`, плюс строки в `ref_firm_product`. API: `GET/POST /catalog/buildings`.

## Иконки

PNG soft-3D по `sku_key` (`/assets/icons/sku/…`).  
`icon_mark` — цифра размера.

## Цены

Итог в строке: `cost`, `price_internal`, `price_shop`.  
НДС / маржи — `ref_fiscal`. Пересев: `docs/_gen_catalog_seed.py`.
