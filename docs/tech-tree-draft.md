# Ветка знаний Civaris — сетка средней подробности

Версия: 2026-08-03  
Источники: тетради автора + дорожная карта + семейства v1.

## Правила

- **Каменный век не моделируем.** Старт летописи = уже деревня с хозяйством.
- Со щелчка уже есть: собирательство, базовые ёмкости для воды, **бумажная валюта** каждой деревни, простой обмен/цены.
- Открытие знания → новые действия, здания, компании, продукты.
- **Кремний** — решение позже; электроника до того может упираться в упрощённую «плату».
- Драгкамни — идея на будущее (роскошь/декор), **не валюта**.

### Календарь (для привязки институтов)

- неделя = 4 дня (позже 3 рабочих + 1 выходной)  
- месяц = 2 недели = 8 дней  
- год = 4 месяца = 32 дня

## Блок 0 — Щелчок (дано, не исследуется)

| ID | Знание | Что уже можно |
|---|---|---|
| S0 | Собирательство плодов | сбор **фруктов** с угодий → закрытие дневных ккал |
| S0 | Гончарство (база) | горшки для воды (личка / запас) |
| S0 | Бумажные деньги | цены, складской учёт в валюте деревни |
| S0 | Общинный строй | деревня ~20 чел., роли черновые |

**Еда на щелчке:** в рацион идут только **фрукты**. Сырые овощи и готовка ещё не «открыты» бытом.

## Фаза 1 кода (что вырезаем из сетки в первый спринт)

Реализуем **поведение** только:

- блок 0 полностью;
- из блока 1: склад, земледелие/садоводство как источник плодов (без всего UI знаний);
- тик дня: сбор → склад → покупка рациона/воды за бумажную валюту деревни.

Справочник знаний в БД можно завести сразу (ID из таблиц выше), но открытие большинства узлов — заглушка `locked` до следующих фаз.
