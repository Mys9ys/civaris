# Civaris — компоновка и дорожная карта

Сводка по `design-notes.md` + предложение, **с чего строить**. Не финальная архитектура — рабочий каркас после диктовок.

---

## 1. Картина целиком (что за игра)

**Civaris** — бог-наблюдатель смотрит, как человечки-кубики размножаются, работают, торгуют, воюют и строят общества: от племени до государств с экономикой, политикой и дипломатией.

Офлайн-урок №1: игра **ломалась на микробыте** (еда, зарплата, одежда каждый день вручную). В цифре быт должен быть **автоматизирован / пакетный**, иначе снова не дойдём до биржи и парламента.

## 2. Слои системы (логическая архитектура)

```
┌─────────────────────────────────────────────┐
│  Игрок (божество): старт, день-кнопка,      │
│  летопись, камеры/статистика, редкие вмешательства │
└─────────────────────┬───────────────────────┘
                      │
┌─────────────────────▼───────────────────────┐
│  Симуляция суток (tick / advance day)       │
│  календарь → потребности → работы → сделки  │
└───┬─────────┬─────────┬─────────┬───────────┘
    │         │         │         │
 люди/гены  мир/карта  экономика  социум
 компании   флора      каталог    политика
 навыки     недра      банк/биржа война
```

| Слой | Суть из заметок |
|---|---|
| **Мир** | генерация планеты, слои почвы/недр, вода/земля/горы, месторождения, растения, стаи |
| **Агенты** | человечки-кубы, гены→навыки→мастерство, жизненный цикл, семьи, рождаемость |
| **Производство** | каталог товаров: сырьё → полуфабрикат → фабрика → готовое (+мусор/тара) |
| **Экономика** | цены, ФОТ, НДС, компании, банк, позже биржа/ПИФы |
| **Социум** | лагеря→поселения→города→страны, партии, выборы, армия |
| **Прогресс** | своё техдерево (Civ только каркас), летопись событий |
| **Хранение** | жители, товары, компании, транзакции — но не «каждая крошка навсегда в горячей БД» |

## 3. Дорожная карта (актуально после раундов 1–2)

### Целевые цифры продукта (v1)

| Параметр | Значение |
|---|---|
| Free-cap населения | **единый потолок 500** на мир; запас роста = 500 − старт → малая **+400**, средняя **+340**, большая **+300** |
| Старт нового мира | **20 чел. / деревня** → 5/8/10 = **100 / 160 / 200**; позиции на щелчке **равные**, дальше расходятся генами |
| Донат-пакеты | +500 (мин), +1000, +2000, +5000 |
| Рекомендуемый hard-cap v1 | **10 000** (50k — следующая эпоха после оптимизации) |
| UI | только **RU** |
| Auth | **VK ID** + альтернатива логин/пароль; email из VK, если API отдаёт |
| Тик дня | HTTP «прожить день» → пайплайн скриптов (покупки, работы, путь до/с работы) |
| Ночной автопрогон | позже |
| Админка | своя тонкая, не Bitrix |

### Фаза 0 — Каркас (1-й блок разработки)

1. Монорепо / структура: `api` (PHP), `web` (Vue), `docs`.
2. MariaDB: миграции пользователей, миров, календарь, летопись.
3. Auth: VK mock + локальный пароль; сессии/JWT — выбрать простое.
4. VK Mini App оболочка + локальный «god mode» без VK.
5. Экран мира-заглушки + кнопка **«День +1»** (пока пустой пайплайн + запись в летопись).
6. Тонкая админка: список миров, форс-тик, просмотр летописи.

### Фаза 1 — Хозяйственный срез (сразу со «щелчка»)

Стартовое состояние мира уже после щелчка (без долгих origin):

1. Сид: **10 независимых деревень-полисов × 25** человечков, склады на поселение; **государств пока нет**.
2. Расклад на карте: **равноудалённо / сильно разбросано**, чтобы первый контакт был не в ближайшие дни/месяцы; эти точки-кандидаты в будущие **столицы**.
3. Каталог / карта ккал: яблоко·груша·банан 100, мандарин 50, виноград 20; олива TBD; вода + горшок.
4. Норма щелчка: **300 ккал + 1 л воды**; микс плодов ок. БЖУ нет. Гены позже могут поднимать норму ккал.
5. Тик дня (пайплайн):
   - потребность / голод → энергия;
   - назначение на сбор/работы;
   - «прогулка» до работы и обратно (упрощённо: стоимость времени/энергии);
   - сбор на склад;
   - пакетное потребление / «покупка» со склада;
   - летопись ключевых событий.
6. Наука: ветка заведена, **собирательство и базовое хозяйство не за гейтом** — они даны со щелчка; открытия цепляют уже следующие слои (инструменты, компании-ремесла…).
7. Кнопки бога — добавлять по мере тестов.

**Эволюция полис → страна (не фаза 1, но принцип):** исходные **10 полисов не разоряются**. Из них **выходят новые города**, захватывают/осваивают земли вокруг; со временем полис обрастает в **страну**, а стартовая точка остаётся столицей. Давление «уничтожить соседа» — не стартовая логика (война/поглощение — отдельный поздний слой, если вообще понадобится).

**Не в фазе 1:** биржа, выборы, полная глина-калькуляция всех горшков как обязательный bottleneck, ночной тик, 50k агентов.

### Фаза 2+

Без изменений по смыслу: глина/вторая цепочка → компании/банк → политика → биржа/война; масштаб и VPS — по факту нагрузки.

## 4. Транзакции и масштаб (важно)

При росте населения «десятки/сотни тысяч оплат в день» **нельзя** хранить как миллионы отдельных row «купил яблоко» в горячей БД навсегда.

Принципы:

1. **Агрегация быта** — суточный рацион/зарплата одной проводкой на агента или даже пачкой по компании/ складу («списание со склада: 20 рационов»), а не 20 микропокупок.
2. **Горячее / холодное** — детальный лог за последние N дней; дальше rollup (сутки/месяц) или архив.
3. **События, не только проводки** — в летопись только интересное; бухгалтерия отдельно и сжато.
4. **Лимит симуляции** — сначала жёсткий потолок населения (офлайн ~200 → цифрой 500–2000), потом оптимизация.
5. **Игровая vs реалистичная шкала** — две шкалы в заметках (10 кг куб vs 65 кг человек); для симуляции лучше **игровая единица**, реалистичные кг — справочник баланса.

Итого: транзакций будет много, но архитектура должна делать их **дешёвыми и сжимаемыми**, иначе повторим офлайн-стену.

## 5. Порядок работ «технику vs геймплей»

| Сначала | Потом |
|---|---|
| день-кнопка + модель агента + склад + еда | красивый рендер, все биомы |
| 1–2 товарные цепочки | полный каталог |
| пакетный учёт | биржа |
| своя узкая симуляция | порт всего Civ-дерева |

Стек и БД — выбрать под фазу 1 (см. вопросы), не под фазу 5.

### Совет: вода и горшки

**Актуально (2026-08-03):** общей цистерны **нет**. Вода — в личных и промышленных ёмкостях; пример: **2×2 л на неделю** на человека. Деревни ставятся **у водоёмов/рек**. Раньше предлагалась цистерна города — **снято**.

### Расклад старта: 10 полисов × 25 (решение 2026-08-01)

Не «сразу государства», а **независимые поселения**:

| | |
|---|---|
| Всего | 250 человечков |
| Поселений | **10** деревень / полисов |
| На поселение | **25** |
| Государства | вырастают из полисов: **новые города + освоение земель**; исходные 10 **не разорять** |
| Карта | точки **примерно равноудалены**, сильный разброс → первый контакт не скоро |
| Столицы | стартовые 10 полисов → столицы своих стран |

Почему так лучше: каждый очаг наращивает хозяйство; страна растёт **наружу** (филиалы-города), а не съедая соседей. 250 уже больше типичного офлайна (~200).

Параметры на потом: мин. расстояние между полисами; условия **основания дочернего города**; скорость освоения земли; первый контакт с чужим полисом.

### Ремарка: старт со щелчка + имена (2026-08-03)

Кнопка **«Начать»** / создание карты:

- превью / «фильм» эволюции от origin **пока пропускаем**;
- сразу точка **1 день · 1 месяц · 1 год** (начало летоисчисления);
- **10 деревень × 25** человечков (ещё не города);
- уже есть какой-то **строй** и **товарно-денежные отношения**.

#### Генератор названий

| Сущность | Правило |
|---|---|
| **страна** (позже из деревни/полиса) | своё имя |
| **национальность** | = **имя страны** |
| **поселение** | **отличается** от названия страны (не «Мексика/Мехико») |

#### Деньги на щелчке

- в **каждой деревне своя денежная единица**;
- валюта сразу **бумажная** (упрощение для товарно-денежных отношений);
- драгкамни — идея на будущее как **роскошь/декор**, не как деньги;
- к старту летописи деньги уже **в обороте**.

#### Потребности человечка на щелчке (формулировка)

На 1.1.1 все деревни стартуют одинаково; дальше судьба зависит от генов и событий.

**Каждый день**

| Нужда | Норма на щелчке | Как закрывается |
|---|---|---|
| Еда | **300 ккал / сутки** (микс плодов ок) | угодья → склад → выдача/покупка |
| Вода | **1 л / сутки** | горшки 1 л; неделя 4 дня → **4 л** |
| Энергия | полная только если ккал+вода закрыты | иначе штраф к выработке |
| Жильё | общежитие на 20 | здание поселения |

**БЖУ не используем** — только калории + вода.

#### Карта калорий плодов (канон v1, `/settings` → «Карта калорий»)

Каталог общий (`ref_catalog`) с типом позиции:
- **съедобное/пища** (`food`) — попадает в карту калорий;
- полуфабрикат / товар / предмет / тара / вода — только во вкладке «Каталог».

Подтипы еды: **фрукты** / **овощи (сырые)** / **овощи (готовка)** / **выпечка**.

### Цепочка доступа к ккал (канон)

1. **Щелчок** — человечки кормятся **фруктами** (собирательство плодов). Норма 300 ккал/сутки закрывается фруктовым миксом.
2. **Огородничество (V2a)** — вторым слоем в рацион входят **сырые овощи**.
3. **Продвинутая кулинария (C12)** — ветка науки/ремесла: можно готовить и есть **овощи (готовка)** (картофель, капуста, тыква, кукуруза, свёкла, баклажан). Ккал в карте = порция после готовки.

Горшок 1 л = **тара**, не еда. Вода = тип **вода**.

**Фрукты** — яблоко/груша/банан/персик 100, мандарин 50, виноград 20.

**Овощи (сырые)** — огурец/салат 100, помидор/морковь/перец 50, оливка 20.

**Овощи (готовка)** — картофель/капуста/тыква/кукуруза 100, свёкла/баклажан 50.

**Выпечка** — пока пусто (откроется с пекарней C8).

Семейства `fruits` / `vegetables` / `vegetables_cook` — сид `seed_families_food_v1.sql`.

Суточная норма **300 ккал** = например 3 яблока, или 6 мандаринов, или 15 ягод, или любая смесь (2 яблока + 2 мандарина и т.д.).

**Гены / рост:** человечки генетически будут «расширяться» — со временем **норма ккал может расти** выше 300. База щелчка остаётся 300; множитель/профиль генов — отдельный слой позже.

*(Цифры крутим в `/settings`: `ref_catalog.kcal` + `ref_click_needs`.)*

**Жильё на щелчке**

- в каждом поселении одно здание — **общежитие** на всех **20** человечков;
- от этой точки потом «скачем»: дом правителя, первый банк, казна и т.д.

**Пока не нужно на щелчке:** электричество, счета ЖКХ, износ одежды, ипотека, досуг.

**Правила:** недоел → меньше выработка; деревня целится на нужды всех **+15–20%** запаса еды/воды.

*(Продолжение ремарки — по диктовке.)*

- деревья, водоёмы, реки;
- деревни **у воды** — без воды человечки не живут;
- равноудалённость очагов + привязка к гидросети;
- **10 деревень — не конечные точки карты**, а стартовые очаги; карта шире, есть куда расти и торговать.

#### Ресурсные «месторождения» / угодья у поселений

У воды и рядом с деревнями — **локации ресурсов** (садовые угодья и т.п.):

- минимум **2** разных угодья на стартовую деревню;
- кому-то может повезти — сразу **3**;
- фрукты **раздельно**, не одним «садом всего»:
  - яблоки, груши, бананы, мандарины, виноград;
  - оливки (ккал пока не заданы);
  - разная калорийность → позже импульс к **международной торговле**.

Итого: локальный набор угодий → специализация деревень → потом обмен между очагами/странами.

#### Карта провинций (как Rome: Total War) — 2026-08-03

Планета сразу поделена на **провинции / области**: в каждой уже есть минимум, чтобы поселение могло жить относительно самодостаточно (вода, еда и пр.). Стартовые деревни — не единственные клетки карты, а выбранные провинции на старте.

##### Размеры карты (выбор при «Начать»)

| Карта | Стартовых деревень | Людей на деревню | Старт total | Запас роста до free-cap 500 | Макс. городов/страна | Провинций |
|---|---:|---:|---:|---:|---:|---:|
| **Малая** | **5** | **20** | **100** | **+400** | **8** | **40** |
| **Средняя** | **8** | **20** | **160** | **+340** | **9** | **72** |
| **Большая** | **10** | **20** | **200** | **+300** | **12** | **120** |

Все деревни на щелчке **в равных стартовых условиях**; расхождение — через гены, угодья провинций и события.  
Гипотеза баланса: **меньше стран (малая карта) → наука в среднем медленнее** (меньше параллельных исследователей) — проверить в симуляции.


Логика роста страны: из стартовой деревни осваиваются соседние **пустые провинции** (до лимита городов на страну), не уничтожая чужие стартовые очаги.

**Каркас UI (2026-08-03):** страница `/map` — два вида (**шар** / **развёртка**) × два слоя (**географическая** / **политическая**), малая карта **40** провинций + **5** стартов. SVG/CSS без анимации вращения.

*(Продолжение ремарки — по диктовке.)*

**Общей городской цистерны нет.**  
Вода в **ёмкостях**:

- личное потребление (горшки / тара);
- отдельно — промышленные объёмы.

Пример обихода: человечек на **неделю** может купить себе **две ёмкости по 2 литра** (в диктовке «две карточки по 2 литра»).

*(Продолжение ремарки — по диктовке.)*

### Ремарка: где начинается «настоящая» игра (2026-08-01)

Офлайн запускался **~7–8 раз**. Три вида происхождения **сами по себе малоинтересны**.

Весь интерес — когда человечки ведут **хозяйство**: компании, банки и т.д.

#### Пороги институтов (пример, прописать отдельно)

- население конклава / племени / деревни достигает порога (напр. **30**) → появляется **банк**;
- ещё +30 → ещё один банк;
- подобные пороги для других институтов — отдельная таблица.

#### Старт = промотка / интро

Начало игры скорее **видео или быстрый прогон**, не долгая симуляция:

- челнок высаживает людей на уже живую планету; или
- коацерватная капля быстро размножается → из моря доисторические существа → … → люди;

Летопись и **календарь начинаются не с создания планеты**, а когда сознательное человечество начинает **считать время** (аналогия «до/после» опорной даты — глубоко в теологию не лезем). Практический якорь: когда человечки переходят к устойчивой **хозяйственной деятельности**.

#### Настройки партии (как карты Civilization)

Перед игрой задавать, например:

- целевое число человечков на «точке старта хозяйства» (напр. **500**);
- сколько **стран / цивилизаций** (напр. **7**);
- параметр планеты: засушливая / много воды → островные государства и т.п.

Племена дробятся (ушли за гору / через реку), размножаются; в какой-то момент — **точка отсчёта**: «готовы собирать, ловить, хозяйствовать» (до этого тоже могут, но счётчик/игра «по-настоящему» включается здесь).

#### Что включается в момент «щелчка» (1 день / 1 месяц / 1 год)

В этот момент фиксируется календарная точка отсчёта и поднимаются базовые системы:

1. **таблица генов** — проработать с автором; на старте **рандомное распределение** (уровни вроде 1, 2, …);
2. **продуктовая корзина** + ежедневные нормы БЖУ (белки / жиры / углеводы);
3. **условия голода / недоедания** → влияние на **энергию** и эффективность труда.

Черновая идея голода:

- если человечек потребляет, условно, **половину** дневной нормы → roughly **половина эффективности**;
- энергия не восполняется полностью при недоедении;
- пример: вместо нормы новичка **13 яблок** собирает порядка **7**.

Всё это нужно отдельно сбалансировать (пороги %, формулы энергии, связь с мастерством).

#### Планета, ресурсы, наука, календарь (продолжение ремарки)

- **Планета** к щелчку уже с **распределёнными ресурсами** (схема распределения — продумать; расклад при генерации).
- В момент щелчка нужна и **линейка развития технологий / науки** (свою, не слепок Civ as-is).
- **Доступность фруктов/растений** — где-то растут, где-то нет (локальная карта/биом), но **без времён года** (пока автор не хочет сезонов).
- Календарь пока: **4 месяца × 6 дней**; на других бумажках были интереснее концепты, но не все листочки с собой (другая квартира) — **в процессе можно изменить**.

*(Продолжение ремарки — по диктовке.)*
