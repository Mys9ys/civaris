# Civaris — компоновка и дорожная карта

Сводка по `design-notes.md` + предложение, **с чего строить**. Не финальная архитектура — рабочий каркас после диктовок.

---

## 1. Картина целиком (что за игра)

**Civaris** — бог-наблюдатель смотрит, как человечки-кубики размножаются, работают, торгуют, воюют и строят общества: от племени до государств с экономикой, политикой и дипломатией.

Офлайн-урок №1: игра **ломалась на микробыте** (еда, зарплата, одежда каждый день вручную). В цифре быт должен быть **автоматизирован / пакетный**, иначе снова не дойдём до биржи и парламента.

---

## 2. Слои системы (логическая архитектура)

```
┌─────────────────────────────────────────────┐
│  Игрок (божество): старт, день-кнопка,      │
│  летопись, камеры/статистика, редкие вмешательства │
└─────────────────────┬───────────────────────┘
                      │
┌─────────────────────▼───────────────────────┐
│  Симуляция суток (tick / advance day)       │
│  календарь → потребности → работы → сделки  │
└───┬─────────┬─────────┬─────────┬───────────┘
    │         │         │         │
 люди/гены  мир/карта  экономика  социум
 компании   флора      каталог    политика
 навыки     недра      банк/биржа война
```

| Слой | Суть из заметок |
|---|---|
| **Мир** | генерация планеты, слои почвы/недр, вода/земля/горы, месторождения, растения, стаи |
| **Агенты** | человечки-кубы, гены→навыки→мастерство, жизненный цикл, семьи, рождаемость |
| **Производство** | каталог товаров: сырьё → полуфабрикат → фабрика → готовое (+мусор/тара) |
| **Экономика** | цены, ФОТ, НДС, компании, банк, позже биржа/ПИФы |
| **Социум** | лагеря→поселения→города→страны, партии, выборы, армия |
| **Прогресс** | своё техдерево (Civ только каркас), летопись событий |
| **Хранение** | жители, товары, компании, транзакции — но не «каждая крошка навсегда в горячей БД» |

## 3. Дорожная карта (актуально после раундов 1–2)

### Целевые цифры продукта (v1)

| Параметр | Значение |
|---|---|
| Free-cap населения | **500** |
| Старт нового мира | **250** (N/2), **2 страны**, по **2–3 города** |
| Донат-пакеты | +500 (мин), +1000, +2000, +5000 |
| Рекомендуемый hard-cap v1 | **10 000** (50k — следующая эпоха после оптимизации) |
| UI | только **RU** |
| Auth | **VK ID** + альтернатива логин/пароль; email из VK, если API отдаёт |
| Тик дня | HTTP «прожить день» → пайплайн скриптов (покупки, работы, путь до/с работы) |
| Ночной автопрогон | позже |
| Админка | своя тонкая, не Bitrix |

### Фаза 0 — Каркас (1-й блок разработки)

1. Монорепо / структура: `api` (PHP), `web` (Vue), `docs`.
2. MariaDB: миграции пользователей, миров, календарь, летопись.
3. Auth: VK mock + локальный пароль; сессии/JWT — выбрать простое.
4. VK Mini App оболочка + локальный «god mode» без VK.
5. Экран мира-заглушки + кнопка **«День +1»** (пока пустой пайплайн + запись в летопись).
6. Тонкая админка: список миров, форс-тик, просмотр летописи.

### Фаза 1 — Хозяйственный срез (сразу со «щелчка»)

Стартовое состояние мира уже после щелчка (без долгих origin):

1. Сид: 250 человечков, 2 страны, 2–3 города/страна, склады городов.
2. Каталог v0: яблоко, виноград, мандарин, вода (+ при необходимости тара — см. совет про горшки).
3. Нормы БЖУ/воды + правило: сбор планируется на **дневную потребность + 15–20%** запаса.
4. Тик дня (пайплайн):
   - потребность / голод → энергия;
   - назначение на сбор/работы;
   - «прогулка» до работы и обратно (упрощённо: стоимость времени/энергии);
   - сбор на склад;
   - пакетное потребление / «покупка» со склада;
   - летопись ключевых событий.
5. Наука: ветка заведена, **собирательство и базовое хозяйство не за гейтом** — они даны со щелчка; открытия цепляют уже следующие слои (инструменты, компании-ремесла…).
6. Кнопки бога — добавлять по мере тестов.

**Не в фазе 1:** биржа, выборы, полная глина-калькуляция всех горшков как обязательный bottleneck, ночной тик, 50k агентов.

### Фаза 2+

Без изменений по смыслу: глина/вторая цепочка → компании/банк → политика → биржа/война; масштаб и VPS — по факту нагрузки.

## 4. Транзакции и масштаб (важно)

При росте населения «десятки/сотни тысяч оплат в день» **нельзя** хранить как миллионы отдельных row «купил яблоко» в горячей БД навсегда.

Принципы:

1. **Агрегация быта** — суточный рацион/зарплата одной проводкой на агента или даже пачкой по компании/ складу («списание со склада: 20 рационов»), а не 20 микропокупок.
2. **Горячее / холодное** — детальный лог за последние N дней; дальше rollup (сутки/месяц) или архив.
3. **События, не только проводки** — в летопись только интересное; бухгалтерия отдельно и сжато.
4. **Лимит симуляции** — сначала жёсткий потолок населения (офлайн ~200 → цифрой 500–2000), потом оптимизация.
5. **Игровая vs реалистичная шкала** — две шкалы в заметках (10 кг куб vs 65 кг человек); для симуляции лучше **игровая единица**, реалистичные кг — справочник баланса.

Итого: транзакций будет много, но архитектура должна делать их **дешёвыми и сжимаемыми**, иначе повторим офлайн-стену.

## 5. Порядок работ «технику vs геймплей»

| Сначала | Потом |
|---|---|
| день-кнопка + модель агента + склад + еда | красивый рендер, все биомы |
| 1–2 товарные цепочки | полный каталог |
| пакетный учёт | биржа |
| своя узкая симуляция | порт всего Civ-дерева |

Стек и БД — выбрать под фазу 1 (см. вопросы), не под фазу 5.

## 6. Открытые решения (нужны ответы)

См. вопросы в чате — без них фаза 0/1 будет гадать.

### Ответы автора — раунд 1 (2026-08-01 вечер)

1. **Сразу сборка под VK**; хостинг сейчас Beget (обычный). VPS — только если упрёмся (см. совет в чате). Локалка: OSPanel + mock VK.
2. **1 игрок = 1 мир**. Пересечение цивилизаций / космос — далёкое будущее.
3. **Ночной автопрогон отложить.**
4. Старт прототипа: **N/2 от лимита** — при лимите 500 → **250 человечков**, **2 страны × 2–3 города**, сразу наука + хозяйство (не песочница origin).
5. Лимит 500 vs 1000 — решение после совета (рекомендация: **500** free-cap, схема заточена под рост).
6. **MySQL/MariaDB** ок при агрегации проводок; не менять без нужды.
7. Первая товарная цепочка — **вынести в следующий раунд вопросов**.

**Админка:** не Bitrix24; своя тонкая админка + правильная разметка БД (совет в чате).

### Ответы автора — раунд 2 (2026-08-01)

1. **Цепочка:** плоды + склад (запас) + вода. Сбор ≥ дневная потребность **+15–20%**. Горшки — риск bottleneck (см. совет).
2. **Auth:** VK + альтернатива с паролем; email из VK, если схема рабочая.
3. **Тик дня** гоняет пайплайн: покупки, работы, путь до/с работы.
4. **UI:** только русский.
5. **Донат:** пакеты +500 / +1000 / +2000 / +5000; потолок — рекомендация **10k** для v1 (50k позже).
6. **Кнопки бога** — наращивать в процессе тестов.
7. **Наука** не блокирует первичные занятия (собирательство и т.п.) — они со **щелчка**; ветка открытий — для следующего слоя.

### Совет: вода и горшки (чтобы не встать на старте)

При 250 человечках и норме ~1,5 л/день нужно ~375 л/день только на питьё.  
Новичок тащит 25 л/день и лепит ограниченное число горшков — **если питьё только из личных горшков, старт ломается**.

Рабочая схема для фазы 1:

- у города есть **источник / цистерна** (река, колодец) → питьё со склада воды **без** обязательного личного горшка на каждый литр;
- горшки — для **переноса и хранения запаса**, вторая цепочка чуть позже или параллельно тонким слоем;
- иначе сначала форсим нереалистично много гончаров и убиваем кайф хозяйства.

### Совет: потолок доната

- **10 000** — честный hard-cap продукта v1 (ещё на Beget+оптимизации достижимо осторожно).
- **50 000** — маркетинг «когда-нибудь» + VPS + пакетная симуляция; не обещать в первом релизе.

### Ремарка: где начинается «настоящая» игра (2026-08-01)

Офлайн запускался **~7–8 раз**. Три вида происхождения **сами по себе малоинтересны**.

Весь интерес — когда человечки ведут **хозяйство**: компании, банки и т.д.

#### Пороги институтов (пример, прописать отдельно)

- население конклава / племени / деревни достигает порога (напр. **30**) → появляется **банк**;
- ещё +30 → ещё один банк;
- подобные пороги для других институтов — отдельная таблица.

#### Старт = промотка / интро

Начало игры скорее **видео или быстрый прогон**, не долгая симуляция:

- челнок высаживает людей на уже живую планету; или
- коацерватная капля быстро размножается → из моря доисторические существа → … → люди;

Летопись и **календарь начинаются не с создания планеты**, а когда сознательное человечество начинает **считать время** (аналогия «до/после» опорной даты — глубоко в теологию не лезем). Практический якорь: когда человечки переходят к устойчивой **хозяйственной деятельности**.

#### Настройки партии (как карты Civilization)

Перед игрой задавать, например:

- целевое число человечков на «точке старта хозяйства» (напр. **500**);
- сколько **стран / цивилизаций** (напр. **7**);
- параметр планеты: засушливая / много воды → островные государства и т.п.

Племена дробятся (ушли за гору / через реку), размножаются; в какой-то момент — **точка отсчёта**: «готовы собирать, ловить, хозяйствовать» (до этого тоже могут, но счётчик/игра «по-настоящему» включается здесь).

#### Что включается в момент «щелчка» (1 день / 1 месяц / 1 год)

В этот момент фиксируется календарная точка отсчёта и поднимаются базовые системы:

1. **таблица генов** — проработать с автором; на старте **рандомное распределение** (уровни вроде 1, 2, …);
2. **продуктовая корзина** + ежедневные нормы БЖУ (белки / жиры / углеводы);
3. **условия голода / недоедания** → влияние на **энергию** и эффективность труда.

Черновая идея голода:

- если человечек потребляет, условно, **половину** дневной нормы → roughly **половина эффективности**;
- энергия не восполняется полностью при недоедении;
- пример: вместо нормы новичка **13 яблок** собирает порядка **7**.

Всё это нужно отдельно сбалансировать (пороги %, формулы энергии, связь с мастерством).

#### Планета, ресурсы, наука, календарь (продолжение ремарки)

- **Планета** к щелчку уже с **распределёнными ресурсами** (схема распределения — продумать; расклад при генерации).
- В момент щелчка нужна и **линейка развития технологий / науки** (свою, не слепок Civ as-is).
- **Доступность фруктов/растений** — где-то растут, где-то нет (локальная карта/биом), но **без времён года** (пока автор не хочет сезонов).
- Календарь пока: **4 месяца × 6 дней**; на других бумажках были интереснее концепты, но не все листочки с собой (другая квартира) — **в процессе можно изменить**.

*(Продолжение ремарки — по диктовке.)*
