# Civaris — правила рельефа и провинций-пазлов

Канон 2026-08-11 (пазлы × сектора). Референс стыковки: Carcassonne.

---

## 0. Сетка

| | |
|--|--|
| Малая карта | **40** провинций (как было, 8×5) |
| Провинция-пазл | **16×16** клеток |
| Сектор | **4×4** клетки → **16 секторов** на пазл (сетка 4×4) |
| Заполнение сектора | **не монолит**: объект лежит «по красоте» внутри сектора (часть клеток) |
| Повторы пазлов | да, с поворотом 0/90/180/270° |
| Кривизна границ провинций | позже; живость — рельефом внутри |

---

## 1. Ландшафтные объекты (в секторах)

Один цвет на семейство. Класс = масштаб объекта (универсальные ступени для воды / зелени / гор).

| Ступень | Вода | Зелень | Горы | Секторов | Охват |
|---------|------|--------|------|----------|--------|
| малый | пруд | сквер | **сопка** | **2–4** | **1** провинция |
| средний | озеро | парк | **гряда** | **6–8** | **2** провинции |
| крупный | море | лес | **горный массив** | **18–26** | много провинций; в одной пазле **≤ 6–7** секторов |

Дополнительно:

| | |
|--|--|
| море в одной провинции | ≤ **6–7** секторов ≈ **≤ ~40%** пазла |
| пляж | **авто** вокруг моря (1–2 клетки), не тип края пазла |
| пустыня / весь мир-океан | **нет** |

---

## 2. Река

| | |
|--|--|
| ширина | **1–2 клетки** (не на весь сектор) |
| сквозной пазл | река через **4 сектора** (на всю провинцию по линии/ломаной) |
| короткий кусок | **2–3 сектора** (исток / поворот / устье) |
| повороты | да; сглаживание внутри сектора (16 клеток) |
| выход на край | **не обязан** быть ровно в середине стороны |
| стыковка | если на общей стороне есть река — соседний пазл продолжает реку |

### Откуда начинать реки (предложение)

| Рельеф | Реки |
|--------|------|
| **сопка** | **нет** истоков (слишком мала) |
| **гряда** | **1** исток |
| **горный массив** | **≥ 2** истока |
| озеро | позже: опциональный сток (не в первой версии) |

Исток → русло (сквозные/повороты) → устье в **море** или **озеро** (или впадение в другую реку).

---

## 3. Стыковка краёв пазла

На каждой стороне, где есть сосед, совпадает **ландшафт**:

- есть река на стыке → река к реке;
- море → море;
- лес → лес;
- горы (гряда/массив на краю) → горы;
- иначе обычно равнина.

Сквер / парк / пруд / сопка — **локальные** (не обязаны быть типом «края», если не дотянулись до границы).

---

## 4. Состав провинции (пригодность)

Каждая провинция-пазл в идеале содержит микс (остальное — равнина):

- немного **воды** (пруд / край озера–моря / река),
- немного **зелени** (сквер/парк/край леса),
- чуть **гор** (сопка или край гряды/массива),
- **не** залита морем целиком.

*Уточнение:* микс — на уровне **провинции**, не обязательно в каждом из 16 секторов (иначе крупный лес/море невозможны).

---

## 5. Сборка карты

1. Каталог прототипов пазлов (число свободное).
2. Раскладка с edge matching + повороты.
3. Крупные объекты (лес/море/массив) собираются из нескольких пазлов, соблюдая лимит 6–7 секторов на пазл.
